**Overview**

FlightDash For Planes is a modern telemetry dashboard widget for EdgeTX 2.11+ transmitters, designed specifically for fixed-wing aircraft and FPV planes. Built for radios such as the RadioMaster TX16S, the widget delivers a clean flight interface with real-time telemetry, animated model image slideshows, trim visualization, timer monitoring, receiver data, transmitter voltage, and flight status information — all optimized for quick readability while flying.

The widget automatically loads aircraft images based on the active model name and supports slideshow image rotation for a more immersive and customizable pilot experience.

Designed with both functionality and aesthetics in mind, FlightDash provides pilots with a compact yet information-rich cockpit view directly on their EdgeTX transmitter.

**Features**
- Real-time telemetry dashboard for fixed-wing aircraft
- Compatible with EdgeTX 2.11+
- Designed for large-screen radios like the TX16S
- Automatic model image loading from /IMAGES/
- Built-in slideshow support for multiple aircraft images
- Motor on/off status display with custom text labels
- Flight mode indicator
- Receiver signal strength monitoring
- Receiver quality percentage display
- Receiver battery voltage monitoring
- Dynamic battery percentage icon with low-voltage warnings
- Color-coded telemetry states and alerts
- Flight timer progress bar with visual warning levels
- TX battery voltage monitoring
- Live date and clock display
- Animated trim position bars for:
  - Aileron
  - Elevator
  - Rudder
  - Throttle
- Automatic image scaling while preserving aspect ratio
- Clean aviation-inspired UI layout
